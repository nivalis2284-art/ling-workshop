# 调试：验证根因，不套固定步骤

先明确实际行为、期望行为和可检查证据；按问题需要采用日志追踪、最小复现、差分、二分或端到端实验。事实、推断、未知明确分开。

不要求每次恰好三个假设、一次只改一个变量或失败三次自动停止。根因明确时可直接验证；线索变化时可调整策略。若没有新信息、成本过高或操作有风险，及时复盘而非无限重试。

修复后检查原问题、相关回归和外部副作用；不将“错误暂未复现”等同于已证实修复。复杂故障跨会话时，将关键复现、已排除方向、未知和下一步保存到 `docs/交接.md`；正式审查结论属于 `docs/审查记录/`，遵守历史归档规则。
