# 交接：最新状态只保留一份

## 两种交接文档

- `docs/交接.md` 是**当前工程事实与恢复入口**，保持单一最新版本，更新时覆盖当前内容；长期历史留在 Git、计划/审查归档和里程碑档案。
- 根目录 `HANDOFF.md` 不是仓库长期维护文件；用户通过 Chat 临时提供的需求材料**不是工程当前状态的替代品**，也不会自动授权执行。

## `docs/交接.md` 建议格式

以简洁 Markdown 记录：

- `# 交接`（可带更新日期）；
- `## 做到哪`：当前事实、所属里程碑与阶段；
- `## 下一步`：按优先级列可继续的工作；
- `## 注意什么`：风险、障碍、未知、手工核对事项；
- `## 已试与假设`：复杂故障时记录尝试及证据，没有可省略；
- `## 事实证据`：提交、检查结果、链接、恢复点，能引用则引用。

长期任务、会话切换、交给其他 Agent 或关键状态变化时及时更新；只处理简单且已完结的任务可简短更新或通过提交记录说明。更新时不能丢掉其他尚未完成任务的有效交接信息。

## 与归档的关系

交接是“现在在哪里”，不是历史归档库。旧阶段的计划与审查归入各自历史目录，里程碑完成时整包归档；`docs/交接.md` 同步指向新的当前工作，不堆叠旧会话流水账。
