## Overview

LingNexus (灵) is an owner-controlled, long-lived personal AI system built as a modular monolith on Windows (`README.md:3-4`, `src/lingnexus/app.py:1`). It provides continuous agent state across restarts, model switching, and roleplay scenes (`README.md:3-4`). The backend runs a local FastAPI loopback service managed by a Windows system tray and desktop launcher (`src/lingnexus/desktop/launcher.py:36`, `src/lingnexus/api/app.py:65`), while the frontend is a React 19 single-page application communicating over loopback HTTP and Server-Sent Events (`frontend/src/app/App.tsx:28`, `src/lingnexus/runtime/service.py:69`).

The system strictly decouples raw experiences (`sources`), derived memory (`episodes`, `knowledge`), self-concept (`self_revisions`), and execution state (`tasks`) (`README.md:68-69`). Correcting a historical source triggers cascading invalidation of derived downstream data without losing audit history (`src/lingnexus/history/service.py:15`, `src/lingnexus/app.py:33-35`).

## Data Flow

### Chat Execution Flow
1. **User Input & Attachment**: The frontend captures the turn via `ChatComposer` and sends a POST request with the owner bearer token to `/api/chat/runs` (`frontend/src/features/chat/ChatComposer.tsx:1`, `src/lingnexus/api/chat.py:40`).
2. **Atomic Source Creation**: `ChatRuntime.submit` records the user prompt as an immutable source turn in `sources` and `source_revisions`, links attachments, and inserts a `chat_runs` entry (`src/lingnexus/runtime/service.py:60-67`).
3. **Context Assembly**: `ContextBuilder` aggregates active owner rules (`OwnerInstructions`), current personality state (`self_revisions`), recent conversation history on the selected branch, and relevant memory cards within strict byte budget limits (`src/lingnexus/context/builder.py:52-80`).
4. **Direct Streaming**: `ModelGateway` sends the payload over `httpx` to the configured provider (Anthropic, OpenAI Chat, or OpenAI Responses) via SSE. Emitted text chunks and thinking tokens are streamed directly to the frontend (`src/lingnexus/models/gateway.py:151-165`, `src/lingnexus/runtime/service.py:69-79`).
5. **Completion & Job Queueing**: Once the model terminates, the assistant response is saved as an immutable source turn. A background consolidation job is enqueued in the `jobs` table (`src/lingnexus/runtime/service.py:74-75`, `src/lingnexus/history/service.py:45-57`).
6. **Background Consolidation**: When the system is idle, `Supervisor` runs `ConsolidationWorker`, which calls the primary LLM to extract new memory episodes, factual knowledge, or identity change proposals (`src/lingnexus/background/supervisor.py:71`, `src/lingnexus/learning/worker.py:61-114`).

### Task Sandbox Flow
1. **Submission**: Owner submits an objective specifying language environment (`python` or `node`) (`src/lingnexus/tasks/service.py:26-33`).
2. **Workspace Snapshot**: Task runtime creates an isolated working copy and captures baseline snapshot digests (`src/lingnexus/tasks/workspace.py:1`).
3. **Execution Loop**: In an isolated Docker container, the model executes commands and tool actions step-by-step up to `max_steps` (`src/lingnexus/tasks/execution.py:18-20`).
4. **Approval & Review**: File modifications and dependency installations require explicit owner approval before being applied to the workspace (`src/lingnexus/dependencies/service.py:35-40`, `src/lingnexus/tasks/service.py:68`).

## Technical Debt

- [ ] **Windows-Exclusive Credential Cache**: Model credential caching currently relies on Win32 DPAPI (`crypt32.dll`), falling back to process memory on non-Windows platforms (`src/lingnexus/configuration/credential_cache.py:19-21`, `src/lingnexus/api/app.py:80`).
- [ ] **Docker Dependency for Sandboxed Tasks**: Code execution relies entirely on local Docker daemon availability; environments without Docker cannot run sandboxed tasks (`README.md:57-58`, `src/lingnexus/tools/docker.py:1`).
- [ ] **Playwright Browser Profile Non-Portability**: Browser session logins and cookies stored in the local Chrome/Playwright profile directory are machine-bound and excluded from portable backup archives (`README.md:71`, `src/lingnexus/maintenance/service.py:27-28`).
- [ ] **Inno Setup Windows Packaging Requirement**: Full binary installer compilation requires an external Inno Setup installation (`ISCC.exe`) (`scripts/build_windows.py:47-60`).
