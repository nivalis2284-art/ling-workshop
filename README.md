# LingNexus · 灵

LingNexus 是由所有者掌握发展方向的**长期个人 AI 系统**；「灵」是其中主要的 AI 个体。当前形态：Windows 本机后台 + 中文图形界面，云端模型驱动。

> **接手必读顺序**：本文件 → [`AGENTS.md`](AGENTS.md)（执行规则）→ [`docs/00-README.md`](docs/00-README.md)（文档地图）→ [`docs/03-路线图/00-README.md`](docs/03-路线图/00-README.md)（现在跑到哪）。

## 当前状态（2026-10-13）

- **第一部分（Agent 地基）**：在跑、可用。对话（流式 / 可见思考 / 分支 / 编辑·重生成·删一轮）、对话内工具调用与多步循环（可暂停 / 恢复 / 中途指导）、权限与副作用确认、执行沙箱（默认零外部依赖，容器可选）、技能包、MCP（可选）、多提供商模型接入与主备切换、备份与维护。
- **第二部分（长期连续与发展、主动关注等）**：已整体隔离——代码封存、不装配、不导入，数据保留；日后逐条加回。
- 最新进度、里程碑与恢复点：见 [`docs/03-路线图/00-README.md`](docs/03-路线图/00-README.md)。

## 快速开始（Windows）

1. 双击根目录 **`start.bat`**：自动补齐环境（首次需联网几分钟）、构建界面、启动本机后台并打开浏览器；
2. 停止：托盘图标 → 退出（黑色窗口不要直接关）。

安装包与详细操作说明见 [`docs/90-使用说明.md`](docs/90-使用说明.md)。
