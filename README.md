# LingNexus · 灵

LingNexus 是由所有者掌握发展方向的**长期个人 AI 系统**；「灵」是其中主要的 AI 个体。当前形态：Windows 本机后台 + 中文图形界面，云端模型驱动。

当前产品定位为**通用 Agent**；编程作为良好、可靠、实用的通用能力之一，不以追平专业编程 Agent 为目标。

> **接手必读顺序**：本文件 → [`AGENTS.md`](AGENTS.md)（执行规则）→ [`docs/地图.md`](docs/地图.md)（项目全景）→ [`docs/交接.md`](docs/交接.md)（做到哪、下一步）。

## 快速开始（Windows）

1. 双击根目录 **`start.bat`**：自动补齐环境（首次需联网几分钟）、构建界面、启动本机后台并打开浏览器；
2. 停止：托盘图标 → 退出（黑色窗口不要直接关）。

安装包与操作说明（归档版）见 [`docs/里程碑/已完成里程碑/首版与第一部分改造/90-使用说明.md`](docs/里程碑/已完成里程碑/首版与第一部分改造/90-使用说明.md)。
