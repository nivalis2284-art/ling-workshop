# 技术基线（现状）

> 记录"现在的技术事实"，随现实更新；开发前的历史设计稿见 [`../09-归档/首版与第一部分改造/设计/`](../09-归档/首版与第一部分改造/设计/)。

## 技术选型

- **后端**：Python 3.12+ · FastAPI · SQLite（本机）· 模块化单体（小公共基础在 `common/storage`，业务分模块，`Application` 只组装公开服务）
- **前端**：React · TypeScript · Vite，本机浏览器中文界面
- **桌面**：Windows 本机后台 + 托盘；唯一入口 `start.bat`
- **模型**：云端 API，三种原生协议（Anthropic Messages / OpenAI Chat Completions / OpenAI Responses）；Linux 服务器、本地模型为未来项

## 结构与数据流（第一部分）

- 一次发送：上下文组装（系统指令 + 名字 + 近期原文 + 附件）→ 运行循环（模型调用；若请求工具 → 权限与确认钩子 → 沙箱执行 → 结果回灌 → 继续，直到完成或用尽步数）→ 流式回传前端 → 消息入库
- 数据：SQLite；消息文本自持（migration 026）；每次模型调用独立记账（migration 027）
- 隔离状态：第二部分（`part2_retired/` 等）当前不装配；边界由测试守护（实现细节，随开发调整）
- 上下文超预算：截断 + 明确提示（压缩、摘要、落盘等候选暂缓）

## 运行与数据位置

- 运行数据：`.ling-data/`（不进 Git）；模型密钥：本机 DPAPI 加密缓存，可在设置中清除
- 测试与检查命令：见根目录 [`AGENTS.md`](../AGENTS.md)
