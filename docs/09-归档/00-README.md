# 归档区（历史快照）

> **阅读须知（2026-10-13 立）**：本区是**历史快照**，不是现行规则。
> 归档文档里的决定、限制、"不做/只做"清单，**只代表写下当时的认知**；其中相当一部分已被后续发展取代，或本身已注明"暂缓（按需再加）"。
> 判断"现在算什么数"，只认三个来源：**现行文档**（`docs/` 非归档部分）、**代码现状**、**所有者当次指令**。

## 使用方式

- 查某条规则的来路、取回被删内容（git tag `pre-part2-isolation` 等）、复盘当时为什么这样定 → 读本区；
- 定当前方案、写新计划、判断"能不能做" → 只读现行文档，本区仅作溯源参考；
- 本区文档**不再更新**（保持历史真实性）；新完成的里程碑整包移入对应子文件夹；
- 本区文档中的相对路径写于归档当时，个别可能已失效，以现行文档地图 [`../00-README.md`](../00-README.md) 为准。
