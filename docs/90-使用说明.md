# 灵的 Windows 首版使用说明

> 当前版本是**第一部分（Agent 地基）**：对话、工具与权限、资料、模型、备份与维护。
> 长期部分（记忆、身份演化、主题分段、技能长期积累、活动与关注）**尚未装配**，
> 所以本文只写现在真正能用的能力。哪些属于长期部分、为什么暂时移除，
> 见 `docs/04-计划/首版与第一部分改造/阶段隔离-长期连续与重建Agent地基-已完成.md`。

LingNexus 可以理解为灵的“住所”：云端模型负责思考，住所保存交流、资料与做事进度。换一个云端模型，好比换一种思考工具；权限与资料仍由本机系统保管。

## 第一次启动

运行安装程序，保持默认的手动启动即可。安装后打开 LingNexus，浏览器会显示本机页面，Windows 通知区域会出现托盘图标。页面只连接本机后台。

1. 创建灵。填写一个名字即可（最多 100 个字符）。初始自我描述、身份演化等属于长期部分，当前版本不涉及。
2. 打开设置，添加模型连接：填写连接名称、接口类型、渠道提供的服务地址、模型名称和密钥，保存后选择为主模型。官方或第三方渠道都可以，须选择它实际提供的协议。
3. 默认参数先保留。根据服务商支持，可以在高级选项启用图片、思考和可选强度；不能把不支持的能力勾上就当成模型已经具备。
4. 回到对话页直接发消息（第一句话会自动创建对话），附件可以直接上传，也可以在资料页面保存后选用。

模型密钥分别保存到当前 Windows 用户加密的本地缓存，退出和重启后自动读取，已有密钥不会显示出来。设置→模型连接→清除模型密钥缓存，会同时清除缓存文件和运行内存中的密钥；模型连接与对话保留。已发出的请求可能继续完成，后续调用需要重新填写。默认缓存路径是 %LOCALAPPDATA%/LingNexus/cache/model-credentials.bin，退出程序后也可手动删除该文件。

可以同时添加多个不同提供商，例如官方服务与第三方渠道。每个连接单独填写协议、URL、模型和密钥，分别选择主模型、备用模型或手动切换；修改一条连接不会覆盖其他连接。修改服务地址需重新提供该连接密钥。

主模型暂不可用时，系统会通知后改用配置好的备用模型，同一次交流继续使用备用；新建交流时先尝试主模型。只有一个模型或备用未配凭据时，失败会如实显示，不会假装已经回复。

## 日常交流与资料

对话页面只有一个持续对话：不需要新建，也不需要切换，第一次发消息时系统自动建好。侧栏右上角的按钮可以把整条侧栏收起来，只留图标。顶部只有对话的名字，右边一个 ⋯ 里放着「批量删除」「任务工作副本」「模型设置」这些偶尔才用一次的东西。

对话里可以直接交办多步工作：灵会在同一个循环里调用工具（读文件、写文件、执行命令等），每一步都显示出来。命令这类有现实副作用的操作会**先弹确认**，经批准后才执行——详见「交给灵做事」一节。

本次对话用哪个模型、思考强度开多高，在输入框右下角那个小按钮里（显示成「模型名 · 强度」），点开就能换。附件在输入框左边的 ＋ 里。消息上的「编辑消息」「删除这一轮」「重新生成」把鼠标移上去才会出现，平时不占视线。换对话、换模型都只影响之后的交流，已经生成的回复不会重算。

## 删掉某一轮对话

把鼠标移到已发送的某条消息上，点「删除这一轮」，就能把这条消息连同灵对它的回复一起删掉。想一次删好几轮，从右上角的 ⋯ 里选「批量删除」，勾选要删的轮次，再点「删除所选」。

删除之前会弹窗说明后果：这些内容会从对话里消失，**之后发给模型的请求里不会再出现它们**，删除后无法撤销。删除是真实移除：这些消息（以及挂在它们下面的旧分支）会从本地资料库里删掉。正在生成回复时不能删除。

消息可以修改、灵的回复可以重新生成。旧版本仍能回看，但只有选定分支会影响后续交流。已发生的现实操作不因编辑消息而撤销。

支持 PNG、JPEG、WebP 图片和 TXT、Markdown、PDF、DOCX、CSV、XLSX 文档。文字解析保留页、段、表格等定位；扫描图片/PDF 需要模型实际视觉能力。文件解析不完整或不能理解时会提示。音视频与图片生成暂不属于首版。

“思考”面板显示服务实际返回的可见内容，可以折叠展开。有些服务不返回，另一些只返回摘要；系统不会补造隐藏思考。

## 系统指令

「设置 → 系统指令」是每次对话开头交给灵的规矩，逐条列出。原先写在程序里的五条也搬到了这里，可以改、可以删、可以加，也能一键恢复成程序默认。这一块管的是说话方式和行为要求；它改不动权限，权限仍在设置里单独授权。

## 长期部分（当前版本不含）

记忆、身份演化与待审批、主题分段、技能长期积累、活动与关注，都属于长期部分，**当前版本尚未装配**。界面上看不到对应入口是正常的，不是故障。哪些内容被暂时移除、为什么，见 `docs/04-计划/首版与第一部分改造/阶段隔离-长期连续与重建Agent地基-已完成.md`。

**技能（技能包）**是当前版本里已经就位的能力来源：把带 `SKILL.md` 的文件夹放进技能目录，灵就能在需要时按需读取其中的方法。加载技能只改变它"知道什么"，不改变它"能做什么"——技能里写的一切动作仍走普通工具、权限授权与执行沙箱。当前没有技能管理界面，靠目录扫描。

## 后台工作

后台工作页面只负责每日自动备份：空闲时按计划检查一次，可以暂停或立即检查。它不处理其它队列，普通聊天、资料与设置都不依赖后台。

## 交给灵做事

日常多步工作**直接在对话里说**即可：不需要先“建任务”，也不需要理解什么时候该用对话、什么时候该建任务。灵会在同一个循环里一步步调用工具（读文件、写文件、执行命令等），每一步都显示出来。

**执行沙箱分两档**（设置 → 执行沙箱）：

- **本地受限执行**（默认）：命令在授权目录内运行，限制进程、内存、CPU 与输出大小，超时即停。开箱可用，不需要额外安装。
- **容器隔离**：需要本机安装并启动容器引擎（例如 Docker Desktop 的 Linux 引擎）并准备镜像。隔离更强，但**是可选项，不是编程任务的前置条件**。

普通聊天、资料与设置**都不需要**容器引擎。网页操作需要本机 Chrome；未安装时须另行准备 Playwright Chromium。

**有现实副作用的操作要先确认。** 执行命令这类动作会在对话里弹出确认卡片，写清将要执行的内容，经批准后才执行；不批准或超时即被拒绝，灵会如实报告被拒，不会假装成功。

1. 在设置中给专用项目文件夹读写授权。读取授权与写入授权分开；其他位置另行授权。
2. 在对话里说明目标和项目文件夹。
3. 灵在授权范围内阅读、修改和测试，每一步都显示出来。可以随时暂停、补充指导、恢复或取消。
4. 测试失败、超时、输出不完整等会保留证据；模型声称成功不能代替实际结果。
5. 「任务工作副本」（对话头部 ⋯ 菜单）保留“先看变更再写回”的审阅流程：在副本里执行、核对文件改动，确认后再写回项目。原项目若已变化，会拒绝旧审阅，避免覆盖项目中的新修改。

容器档默认不联网、非 root、限制资源，不访问宿主命令行、Docker socket 或模型密钥。缺依赖时只提出候选；在界面核对精确版本和一次联网安装计划后确认。安装后还会离线核对实际版本，再让任务继续。不会自动安装任意宿主软件。

Node 环境可以执行当前 Node 支持的 TypeScript 语法擦除，不等同于完整 TypeScript 类型检查。需要 tsc 或项目依赖时走依赖审批。Linux 容器也不代表能测试 Windows 专用程序。

## 网页

网页操作使用独立浏览器资料，不借用日常浏览器登录。按页面指引打开专用浏览器，自己登录，并授权具体网站。填写可以在允许范围进行；发送、提交、购买、删除等重要动作按单次审批执行。结果不明时先核对网页，不盲目重复提交。

**主动关注与提醒**（活动与关注页面）、以及由它驱动的后台主动行为，属于长期部分，当前版本尚未装配。

## 备份、恢复与退出

设置中可以选择本机或外置硬盘的专用备份目录。默认每日在空闲时保存一份、保留 14 份（默认值，可在设置中调整）。备份包括数据库、附件以及任务副本、基线和安装依赖；任务临时目录内容不保留。

手动备份产生 .db 文件与同名 .db.assets 文件夹，两者必须一起保存。导出产生带校验清单的可读资料文件夹。执行中的任务或不确定的依赖安装需要先停稳核对，不能制作自称完整的活动副本。

恢复步骤是“选择来源 → 验证预览 → 确认排队 → 退出 → 重新启动”。下次启动前独占资料目录应用恢复，并保留恢复前的回滚备份。不要手动用旧数据库覆盖正在运行的数据库。模型密钥和专用网页登录资料不随便携导出恢复，必要时重新提供或登录。

关闭页面后，灵仍在托盘运行。从托盘退出或设置里的明确退出入口停止程序。登录启动默认关闭，可以自行开启。卸载保留资料，安装目录与数据目录独立。

## 常见情况

| 现象 | 处理方向 |
| --- | --- |
| 重启后提示缺密钥 | 正常重启自动读取缓存；若已清除、损坏或换 Windows 用户，在编辑连接重新填写 |
| 不返回文字或一直思考后结束 | 检查该渠道的输出额度，思考也会占用额度；失败不是正常答复 |
| 费用显示未知 | 填写实际渠道价格；旧调用缺失价格/用量不能倒算成准确账单 |
| 某次记忆错误 | 查看来源后更正，必要时更正原始来源；保留证据 |
| 任务被阻止或结果待核对 | 展开实际执行记录；确认依赖、权限、测试或引用变动 |
| Docker 不可用 | 启动 Docker Desktop 的 Linux 引擎并准备所需镜像 |
| 备份失败 | 停稳任务，检查磁盘空间/目录权限/外置设备；原资料不会因此删除 |
| 关闭页面仍有通知 | 后台继续是当前规则；需要停止时明确退出或暂停后台 |

LLM 的答案和主动判断需要持续校正。首版提供可以核对、纠正、恢复的机制；真实验证的范围与局限详见验证文档。
