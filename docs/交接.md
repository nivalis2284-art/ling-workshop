## 注意什么

- 不能仅凭同 branch ID、新 episode ID 或摘要声称连续。必须有任务状态版本、实际决策/未完成项可读、旧归档 hash 不变、指导实际消费、旧 effect 不重放等证据。
- 现有 branch 仍有以下缺口：archived 是终态、paused 混合普通回合结束与真实暂停、重启不自动恢复 work run、指导在提交后 UI 早报交付、归档经历按钮使用随机 archive_id（真实 ID 为 work-live:branch_id）、权限仅 confirm/full、本地命令无文件/网络隔离。
- fork 背景不是整个主干易失快照：主干普通 append 通常保持已选前缀有效，但编辑、删除、换支、附件变化或授权撤销会使相关来源失效。唤醒和经历校验要区分历史快照合法性与主干当前绑定，不能把正常增长误判为失忆。
- 子 Agent 的有效权限不能超过父级与环境能力。N0/N1 必须在命令、stdio/HTTP MCP、浏览器和依赖安装等真实通道验证；无法隔离的组合禁用或要求 VM/容器，禁止只做 UI。L4 不突破 OS、VM、账号和网络硬边界。模型网关基础网络另账。
- 首版仍保持一个主干运行和一个子 Agent 执行运行；其他 branch 休眠或排队。并发多 Agent 需另行隔离/资源证据。
- 旧 N16 正式性能报告仍缺失；N12 语义质量、N17 真实 provider/所有者体验仍未关闭。不要用旧 M2 结果证明新任务连续性。
- 本轮没有产品代码、迁移或 .ling-data 改动；不得把计划修订当成实现完成。普通工程决策可自行推进，重大产品方向/新增付费模型测试需确认。
