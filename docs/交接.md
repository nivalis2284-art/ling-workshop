## 注意什么

- 不能把同 branch ID、同 episode 或一段摘要单独当作连续性证明；必须能读到前一版任务状态、真实决策/未完成项、后继 run 实际请求，并验证旧归档 hash、effect、checkpoint 不变。
- 迁移是加性的，但恢复运行库前应先停应用；备份、附件、任务与私有 checkpoint/effect 分别保护。不要把代码回退与数据库恢复混为一步。
- 当前暂停是步骤边界语义，不会强杀正在执行的工具；unknown、待审交付或来源失效仍须阻断自动继续。
- 旧 N16 正式性能报告仍缺失；N12 语义质量与 N17 真实 provider/所有者体验仍未关闭。本轮自动化通过不能替代它们。
