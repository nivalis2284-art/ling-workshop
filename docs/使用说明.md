# 灵的 Windows 首版使用说明

你可以把 LingNexus 理解成灵的“住所”：云端模型负责思考，住所保存经历、当前状态和做事进度。换一个云端模型，好比换一种思考工具；有效的人格、经历与权限仍由本机系统保管。

## 第一次启动

运行安装程序，保持默认的手动启动即可。安装后打开 LingNexus，浏览器会显示本机页面，Windows 通知区域会出现托盘图标。页面只连接本机后台。

1. 创建灵。在身份审阅页面建立初始自我描述；这是可以发展和纠正的起点。
2. 打开设置，添加模型连接：填写连接名称、接口类型、渠道提供的服务地址、模型名称和密钥，保存后选择为主模型。官方或第三方渠道都可以，须选择它实际提供的协议。
3. 默认参数先保留。根据服务商支持，可以在高级选项启用图片、思考和可选强度；不能把不支持的能力勾上就当成模型已经具备。
4. 回到对话，新建对话并发送消息。附件可以直接上传，也可以在资料页面保存后选用。

模型密钥分别保存到当前 Windows 用户加密的本地缓存，退出和重启后自动读取，已有密钥不会显示出来。设置→模型连接→清除模型密钥缓存，会同时清除缓存文件和运行内存中的密钥；模型连接、对话和记忆保留。已发出的请求可能继续完成，后续调用需要重新填写。默认缓存路径是 %LOCALAPPDATA%/LingNexus/cache/model-credentials.bin，退出程序后也可手动删除该文件。

可以同时添加多个不同提供商，例如官方服务与第三方渠道。每个连接单独填写协议、URL、模型和密钥，分别选择主模型、备用模型或手动切换；修改一条连接不会覆盖其他连接。修改服务地址需重新提供该连接密钥。

主模型暂不可用时，系统会通知后改用你指定的备用模型，同一次交流继续使用备用；新建交流时先尝试主模型。只有一个模型或备用未配凭据时，失败会如实显示，不会假装已经回复。

## 日常交流与资料

对话页面像常见的聊天工具：左边一列是你的所有对话，点一下就切；左上角的「＋ 新聊天」开新的一段。侧栏右上角的按钮可以把整条侧栏收起来，只留图标。顶部只有当前对话的名字，右边一个 ⋯ 里放着「对话分支」「交流主题与分段」「模型设置」这些偶尔才用一次的东西。

本次对话用哪个模型、思考强度开多高，在输入框右下角那个小按钮里（显示成「模型名 · 强度」），点开就能换。附件在输入框左边的 ＋ 里。消息上的「编辑消息」「删除这一轮」「重新生成」把鼠标移上去才会出现，平时不占视线。换对话、换模型都只影响之后的交流，已经生成的回复不会重算。

## 删掉某一轮对话

把鼠标移到你说过的某条消息上，点「删除这一轮」，就能把这条消息连同灵对它的回复一起删掉。想一次删好几轮，从右上角的 ⋯ 里选「批量删除」，勾选要删的轮次，再点「删除所选」。

删除之前会弹窗说明后果：这些内容会从对话里消失，**之后发给模型的请求里不会再出现它们**；由它们产生的记忆和身份变化也会一起作废，删除后无法撤销。原始记录本身仍保留在底稿里（盖了"作废"章），随时可以查证发生过什么。正在生成回复时不能删除。

普通自然交流默认属于现实经历。必要时进入你设定的临时场景，退出后恢复现实交流。虚构场景资料单独归属，不会成为灵现实中的身份或经历。

你可以修改自己的消息或重新生成灵的回复。旧版本仍能回看，但只有选定分支自动影响后续交流和记忆。已发生的现实操作不因编辑消息而撤销。

支持 PNG、JPEG、WebP 图片和 TXT、Markdown、PDF、DOCX、CSV、XLSX 文档。文字解析保留页、段、表格等定位；扫描图片/PDF 需要模型实际视觉能力。文件解析不完整或不能理解时会提示。音视频与图片生成暂不属于首版。

“思考”面板显示服务实际返回的可见内容，可以折叠展开。有些服务不返回，另一些只返回摘要；系统不会补造隐藏思考。

## 记忆与灵的发展

后台把交流和行动整理成有来源的事件卡、知识和反思。可以在记忆页面查看、更正、归档、删除派生卡，并打开来源核对原文。保留原文相当于保留档案，事件卡相当于目录和便签。

身份审阅页面从上到下分成三块：

- **系统指令**：每次对话开头交给灵的规矩，逐条列出。原先写在程序里的五条也搬到了这里，可以改、可以删、可以加，也能一键恢复成程序默认。这一块管的是说话方式和行为要求；它改不动权限，权限仍在设置里单独授权。
- **当前身份**：七个部分（身份理解、性格、习惯、关系、价值观、能力、自定义条目）一直列着，空的也显示。点名字展开就能添加、修改、删除，每条都能展开看到它的依据。
- **待审批**：灵自己提出来、等你决定的变化，按同样的七个部分归类。这里你只决定通过或不通过，不需要写内容。

普通经验与低风险行为调整可自动形成。涉及身份、关系、价值判断、重大人格变化或重要能力变化的内容会进入待审批候选，确认后才生效。你也可以随时自己写、自己改、自己删，或回退到任意旧版本。回退不会撤销现实动作。

技能保存经过验证的方法，默认作为候选等待审阅。激活、禁用和版本恢复均有入口；技能文本不提供新权限。长期目标可在任务页面查看和维护，重要方向仍须确认。

后台工作页面可查看整理队列和失败原因、暂停或主动运行。整理失败不会留下半生效的人格变化；重试可能产生新的云端调用。

## 交给灵复杂任务

需要编程时，本机安装并启动 Docker Desktop 的 Linux 容器环境，准备 python:3.12-slim 和 node:24-bookworm-slim 镜像。普通聊天和记忆功能不需要 Docker。网页操作需要本机 Chrome；未安装时须另行准备 Playwright Chromium。

1. 在设置中给专用项目文件夹读写授权。读取授权与写入授权分开；其他位置另行授权。
2. 在任务页面填写目标和项目文件夹，选择 Python 或 Node.js / TypeScript，再创建任务。
3. 灵在项目副本里阅读、修改和测试。可以离开页面，后台继续；也可以暂停、补充指导、恢复或取消。
4. 查看“已验证”状态、最终答复和执行记录。测试失败、超时、输出不完整等会保留证据；模型声称成功不能代替实际结果。
5. 点击审阅文件改动，核对差异，下载成果或确认写回。原项目若已变化，会拒绝旧审阅，避免覆盖你的新修改。删除和二进制改动需下载后手动处理。

默认容器不联网、非 root、限制资源，不访问宿主命令行、Docker socket 或模型密钥。缺依赖时只提出候选；在界面核对精确版本和一次联网安装计划后确认。安装后还会离线核对实际版本，再让任务继续。不会自动安装任意宿主软件。

Node 环境可以执行当前 Node 支持的 TypeScript 语法擦除，不等同于完整 TypeScript 类型检查。需要 tsc 或项目依赖时走依赖审批。Linux 容器也不代表能测试 Windows 专用程序。

若任务引用的记忆、自我或来源在运行时被纠正，任务会停下，以 memory_changed 或 self_changed 提示。它保留此前实际行动和成果，但不会把旧推断标成已验证。检查旧任务后，创建新任务，让灵按有效资料重新处理。

## 网页与主动关注

网页操作使用独立浏览器资料，不借用你的日常浏览器登录。按页面指引打开专用浏览器，自己登录，并授权具体网站。填写可以在允许范围进行，发送、提交、购买、删除等重要动作按单次审批执行。结果不明时先核对网页，不盲目重复提交。

在活动与关注页面创建提醒、指定文件或网页关注、关注事项回顾。网页/RSS 需要先授权对应网站，文件需要读取授权。灵也能在预先授权的低风险范围创建后续活动，重要边界仍由你决定。

主动活动依靠后台仍在运行、电脑未关机休眠和相应网络可用。没有新进展时不反复通知，暂停/撤权后不通过恢复绕过。主模型负责深入判断和形成消息；Jev 是可选辅助，需要独立验证，首版不以它作为唯一入口。

## 备份、恢复与退出

设置中可以选择本机或外置硬盘的专用备份目录。默认每日在空闲时保存一份、保留 14 份。备份包括数据库、附件以及任务副本、基线和安装依赖；任务临时目录内容不保留。

手动备份产生 .db 文件与同名 .db.assets 文件夹，两者必须一起保存。导出产生带校验清单的可读资料文件夹。执行中的任务或不确定的依赖安装需要先停稳核对，不能制作自称完整的活动副本。

恢复步骤是“选择来源 → 验证预览 → 确认排队 → 退出 → 重新启动”。下次启动前独占资料目录应用恢复，并保留恢复前的回滚备份。不要手动用旧数据库覆盖正在运行的数据库。模型密钥和专用网页登录资料不随便携导出恢复，必要时重新提供或登录。

关闭页面后，灵仍在托盘运行。从托盘退出或设置里的明确退出入口停止程序。登录启动默认关闭，可以自行开启。卸载保留资料，安装目录与数据目录独立。

## 常见情况

| 现象 | 处理方向 |
| --- | --- |
| 重启后提示缺密钥 | 正常重启自动读取缓存；若已清除、损坏或换 Windows 用户，在编辑连接重新填写 |
| 不返回文字或一直思考后结束 | 检查该渠道的输出额度，思考也会占用额度；失败不是正常答复 |
| 费用显示未知 | 填写实际渠道价格；旧调用缺失价格/用量不能倒算成准确账单 |
| 某次记忆错误 | 查看来源后更正，必要时更正原始来源；保留证据 |
| 任务被阻止或结果待核对 | 展开实际执行记录；确认依赖、权限、测试或引用变动 |
| Docker 不可用 | 启动 Docker Desktop 的 Linux 引擎并准备所需镜像 |
| 备份失败 | 停稳任务，检查磁盘空间/目录权限/外置设备；原资料不会因此删除 |
| 关闭页面仍有通知 | 后台继续是当前规则；需要停止时明确退出或暂停后台 |

LLM 的答案和主动判断需要持续校正。首版提供可以核对、纠正、恢复的机制；真实验证的范围与局限详见验证文档。
