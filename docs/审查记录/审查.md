## 审核发现与修正

1. **未返回effect_id时漏查执行中行动**：写入后结果落库异常时，逐文件状态缺少行动编号，持久action仍为executing。新增故障回归先复现失败，再按agent及原确定性request_id查找行动；executing继续阻断剩余审阅，unknown记录不覆盖。提交`d224281`。
2. **浏览器正文缺少下一页地址**：正文只有链接文字，模型无法可靠取得导航目标。补充最多100项可见HTTP(S)链接，每项URL≤8192字符、文字≤500字符，检查最多101项；过滤隐藏、脚本、带凭据和无效URL。原page_version及来源授权继续校验，读取链接不授予新来源权限。真实Chrome回归包括越源拒绝。提交`6f3ade3`。
3. **控制器误判业务目标**：英文匹配把正确中文翻译判失败；审批任务因旧页面版本错误保留needs_review，不等于业务结果失败。新判定仍要求全部事实和准确来源，审批独立要求POST前0次、最终1次、值正确、真实DOM完整回读；保留runtime.verified的保守状态，不改产品状态制造通过。正反回归拒绝错误时间、房间、来源、缺回读和重复提交。提交`086e13b`。
4. **控制器临时目录清理误报**：Chrome嵌套文件消失导致FileNotFoundError，不能据此认定根目录删除。改为检查实际根目录是否消失，再记清理结果；新增失败回归。旧报告中的原清理标记保留，最终以独立核对为准。提交`ecde516`。

没有放宽流ID、工具参数或终止校验，没有新增坏流自动重试，没有更换模型、服务商或付费方案。Responses是同一既有通道和glm-5.3-flash的产品已支持协议，仅隔离评测使用；未修改所有者现有模型配置。
