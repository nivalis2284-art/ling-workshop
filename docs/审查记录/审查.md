## 独立复核备注（非阻塞，如实登记）

1. **复核发现-1（已修正）**：`ChatPage` 完全访问状态在**切换对话时**未先重置，若新对话读取失败会沿用上一段的徽标（低严重度显示瑕疵，方向不构成越权——唯一动作只会置回 confirm）。已修：切换时先回归安全默认（`c39efec`），复测 build ✓ + 138 passed。
2. **性能观察**：`access.mode()` 每次 gated 调用在事件循环上做一次同步 DB 读，开销可忽略（登记为设计观察，非缺陷）。
3. **并发安全性**：gated 调用（`run_command`/`mcp__*`）不在只读并发集合内，恒为单元素批次、步内严格串行；full 放行路径不触碰共享内存状态——复核判定无竞态。
