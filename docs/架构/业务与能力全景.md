## 二、业务地图

**交流与行动**

- **持续对话**：流式回复、可见思考、编辑自己的消息 / 重新生成 / 按轮删除、分支切换、附件（图片与常见文档）。
- **对话即循环**：对话内直接调用工具、多步执行（计划→执行→观察→修正）、暂停 / 恢复 / 中途补充指导、有副作用的操作实时确认。
- **任务工作副本**：对话内的次级入口，承载"先看变更再写回"的审阅流程。

**运行与守护**

- **模型接入**：多提供商、三种原生协议、主备切换、可保存设置与命名预设。
- **执行沙箱**：默认"目录受限 + 资源限制"（零外部依赖）；容器按需启用。
- **权限**：目录读写边界、重要操作单次确认。
- **数据保管**：自动备份（默认 14 份、可配置）、恢复保护、可读资料导出。
- **状态与用量**：执行进度、真实用量与费用（缺失时如实标注 unknown）。

**（已隔离）长期连续与发展**：经历与记忆、自我状态与候选审批、后台整理、技能长期积累、长期目标、主动关注——目前不参与运行。
