# 完整 Windows 首版实施总计划

用户已审阅对话中的详细总计划并要求实现。本文件固化执行范围，替代“只有 M0 就完成”的解释。具体基础数据设计见 ../设计/2026-10-08-实现基线.md，早期 M0 任务是基础切片，不是全部目标。

## 交付边界

Windows 单所有者、单主要个体灵；本机 GUI 和后台，云端三端点，流式、思考、主备、事件记忆、可演化状态、技能学习、复杂任务、隔离编程、网页操作、授权的持续关注及主动活动、备份恢复与安装包。关闭页面后台继续，明确退出停止；默认手动启动，自启可选。Linux 服务端、本地模型、多设备、音视频、图片生成不是本次范围。

## A 工程与风险验证

- 虚拟环境、依赖锁、Git、静态检查与测试。
- 最小服务、HTTP/SSE、三协议原生流及工具续接验证。
- Docker Desktop + WSL2 实际隔离运行，最小打包启动／退出验证。
- 测试区分模拟、真实模型、最终端到端。

## B 长期连续基础

- 原始经历及来源修订；派生资料与原文分开。
- 普通变化自动、受保护变化待审阅；审批检查来源、版本和累计影响。
- 当前人格可演化，初始化只一次，重启／压缩／换模型不重置。
- 修正来源使关联资料失效；独立后续成长保留；回退不能撤销现实动作。
- 事件卡、知识、目标、关注事项、上下文清单、导出恢复。

## C 图形交流与模型

- 五入口：交流、经历与记忆、灵的发展、任务与关注、设置与维护。
- 三端点、保存配置、主／备用、高级预设、思考展示和真实用量。
- 故障通知后自动用指定备用；本次交流不因恢复中途切回，正式新交流优先主；历史整理不触发切回。
- 主题／时间自动分段可纠正；用户消息可编辑、灵回复可重新生成；只有选定分支影响未来。
- PNG/JPEG/WebP、TXT/MD/PDF/DOCX/CSV/XLSX 输入；保留定位；无法理解时明示。文字和实际文件输出。
- 真实测试服务由用户提供，密钥仅在内存使用；不保存到项目、日志、凭据库。

## D 自动记忆、学习与演化

- 新增事件增量整理，阶段完成／暂停归档，未完事项独立保存。
- 事件关联→目录／时间→全文与别名→事件卡→原文；中文短词和模糊指代验证。
- 自动带少量相关线索，允许主动查档；不依赖向量库和图谱。
- 有来源知识、反思、技能、候选人格分开；真实结果检验学习，不把生成 Skill 当作成功。
- 有限上下文与稳定前缀，必要纠正优先生效；来源引用与工具续接完整。

## E Agent 与隔离执行

- 计划→行动→结果→修正→交付，支持中途指导、暂停、取消、恢复。
- Python 和 Node/TypeScript 容器环境，指定项目副本挂载，非 root、无特权、无 Docker socket／凭据、默认无网络及资源限制。
- 依赖安装按任务授权联网；只在允许工作目录同步成果，检查原文件变动和冲突。
- 网页独立身份资料，用户登录；发送／发布／购买／删除按重要操作确认。
- 技能按需加载、创建／修订、验证、禁用和回退；能力变化不扩权。

## F 主动活动

- 时间、指定文件、指定网页／RSS、工具结果成为事件。
- 关注事项→观察→去重→关联记忆／目标→判断→查证／交流／行动→反馈。
- 用户优先、后台受控并发、错过合并、不重复行动；暂停／撤权在恢复后有效。
- Jev 可选适配、先旁路评估，不能成为唯一注意入口；未配置可用规则和既有模型。

## G 维护与成品交付

- 中文首次设置、GUI 目录授权、用量费用、日志脱敏、故障诊断。
- PyInstaller 目录式打包 + Inno Setup；开始菜单、桌面入口、pystray 托盘、后台单实例。
- 回环监听、Owner 令牌／Origin 校验，模型密钥不发前端。
- SQLite 在线备份、附件清单、恢复前保护、版本迁移及可读导出。
- 每日备份默认保留14份（可配置），不借备份清理删原始长期历史。
- 安装／升级／卸载保留用户资料、使用说明、完整测试报告和已知限制。
