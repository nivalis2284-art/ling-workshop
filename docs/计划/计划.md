# 阶段计划：技能体系化与地图扩充（GSD 方法迁移）

> 2026-10-14 ｜ 状态：待确认 ｜ 所属里程碑：无（文档体系自举，不单独建立里程碑）

## 目标

把 GSD（get-shit-done-for-antigravity，MIT 许可）的成熟工作方法翻译进 `.agents/skills/`：5 个现有技能加厚，新增「执行（execute）」与「调试（debug）」两个技能；同时把 `docs/地图.md` 扩充为完整结构地图（补「技术栈 / 数据流 / 关键代码入口」），让任何接手 AI 快速掌握项目全貌。

## 依据

- 所有者指令（2026-10-14）：①「把 GSD 的那套工作流迁移成 skill」；②「地图……太过于简略了」。
- 调研结论：GSD = 27 个工作流 + 12 个技能。其中 18 个工作流、7 个核心技能的方法归入本项目 7 个技能；9 个工作流不迁移（install / update / help / whats-new / web-search / new-project / add-todo / check-todos / sprint——工具类或不适用）；5 个上下文管理配件不迁移（依赖 Antigravity 机制）。
- 翻译对照：STATE→交接、ROADMAP→当前里程碑、PLAN→计划、VERIFICATION→审查。
- 取向：搬方法、不搬壳；技能按「默认做法 + 理由」写，不立铁律；每份技能尾部注明 GSD 出处（MIT）。
