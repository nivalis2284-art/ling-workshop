# 阶段计划：开场白优化与工具并发执行

> 2026-10-14 ｜ 状态：待确认 ｜ 所属里程碑：M1「继续优化地基」阶段1

## 目标

让模型在开工前直接掌握运行环境（不再自行摸索），并让同一回合内相邻的只读工具调用并发执行——两处改动均以「行为有测试证据、既有安全属性不回归」为完成线。

## 依据

- 所有者指令（2026-10-14）：M1 第一阶段先处理「优化开场白（给模型的系统指令）」与「多个工具同时请求」两项。
- 同日骨架质量评估结论（见当日会话与工作日志）：
  - 开场白现状＝所有者规则＋名称＋技能索引，缺「环境事实」（平台、工作目录、执行边界、时间）；业界研究（Meta-Harness、Terminal-Bench 等）显示开工前交代环境可省 2–5 轮探索，属低成本高回报项。
  - 同回合多个工具目前严格顺序执行，模型批量读文件 / 搜索时白白变慢；本项目取向为「只读成组并发、其余保持顺序」——保序、可重放、不碰确认闸门。
- 复用既有机制：目录授权取自 `permissions`；执行档位与边界取自 `SandboxService.info()`；前端事件消费按 `call_id` 逐条处理（已核实），成组并发不破坏呈现。
- 取向说明：环境块是「事实陈述」，不是行为约束；行为引导只作为默认规则的可选增补（见文末待确认问题）。

## 不改什么（边界）

- `models/` 三个协议族的原生拼装与网关不改；
- 权限模型与确认闸门不改（`run_command`、MCP 仍逐条确认、顺序执行，只保证并发不绕过它们）；
- 技能索引、附件流程、事件格式与前端不改（已核实按 `call_id` 消费）；
- 不扩大并发范围到写操作 / 命令 / 浏览器（保持现状；后期如要扩大，另行立计划）；
- 不碰 `part2_retired/`；不做打包发布；不改 `start.bat`。

## 执行步骤

### 任务 1：环境事实块（A1 / A2）

- 文件：`src/lingnexus/context/builder.py`、`src/lingnexus/runtime/payload.py`
- 做法：开场新增「运行环境」段：平台；当前日期时间；可写目录与可读目录（来自权限授权，无授权时如实说明）；命令执行可用性与档位边界（来自沙箱描述：本地档＝无 shell、有超时与资源上限、非文件系统 / 网络隔离）。全部取自既有来源，不新设配置项；每项一句，不塞完整清单。
- 验证：`pytest tests/ -q` 全过；新增断言：mock 请求体中系统开场含「运行环境」段与工作目录信息；未授权场景含「命令不可用」字样的如实说明。
- 完成标准：任一聊天请求的开场均含环境段；两类场景（有授权 / 无授权）文字如实；既有测试无回归。

### 任务 2：默认规则增补（A3，待确认后实施）

- 文件：`src/lingnexus/configuration/instructions.py`
- 做法：默认规则增补 1 条工作方式条目（例：「完成任务前先验证结果；多步任务逐步推进，失败如实报告」）。`reset()` 语义不变；已自定义规则的个体不受影响。
- 验证：相关测试全过；设置页「默认」列表随接口自动呈现（无前端改动）。
- 完成标准：新装 / 重置后的默认规则含该条；已自定义者不受影响。

### 任务 3：只读调用并发执行（B1 / B2）

- 文件：`src/lingnexus/runtime/service.py`、`src/lingnexus/runtime/scope.py`
- 做法：回合内扫描调用序列，相邻只读调用（`read_file`、`search`）合为一组并发执行（文件 IO 让出事件循环、真正重叠）；组间与其余调用保持原顺序；结果与事件（started / result）按请求顺序落账（重放确定性）；每次调用独立绑定效果编号。
- 验证：全量测试；新增用例：一回合含「读A、读B、写C」→ 前两条并发执行、结果齐全且顺序不变；并发性以探针验证（两条读取彼此进入后才放行）；含 `run_command` 的回合确认交互不变。
- 完成标准：并发组行为可重复、事件顺序确定；确认与权限拒绝行为逐条不回归。

### 任务 4：实测与收尾

- 文件：`docs/审查记录/审查.md`、`docs/交接.md`、`docs/计划/计划.md`、`docs/里程碑/当前里程碑.md`
- 做法：独立复核（另起只读子代理按验收标准逐条核证）→ 落审查记录；本机启动实测一轮真实对话（观察：模型能直接说清环境；批读回合正常且更快）→ 结果如实记录；更新交接与阶段表。
- 验证：复核清单逐条有证据；实测输出贴入审查记录。
- 完成标准：阶段表状态更新；工作区干净、提交已推送。
