# 阶段计划：完全访问开关 + 前端UI重构（联合执行）

> 2026-10-14 ｜ 状态：已确认（2026-10-15 开工） ｜ 所属里程碑：M1「继续优化地基」阶段2+3（联合执行）

## 目标

一次开工完成两件事：① **「完全访问」开关**——按对话生效的免确认模式（后端机制 + 新界面接线）；② **前端界面整体重构**——按已定稿的可交互原型重写全部界面（iOS 浅白圆润风、浅蓝点缀、五项导航、流畅动效），并把①的界面一起做进去。

## 依据

- 所有者指令链（2026-10-14）：阶段2 三点决定（按对话 / 覆盖命令与远程工具 / 警示条 + 一键关）；阶段3 插入前端重构（先草图、后定稿）；本日最终指令——**设计定稿写入计划、阶段2 与阶段3 联合执行**。
- 设计定稿过程：对话内草图 v1→v5 → 完整可交互原型（32 项自动交互验证通过）→ 三轮反馈全部落定。
- **设计定案（本计划生效）**：
  - 视觉：iOS 浅白圆润风——背景 `#F2F2F7`、白卡片、发丝边框、大圆角；系统字体栈（-apple-system / 苹方 / 微软雅黑）。
  - **动效（所有者补充要求）**：全界面做到「流畅、不普通」——页面与列表**编排入场**（错峰 50–120ms、封顶约 250ms）、弹层与弹窗缩放入场、消息入场、按压与悬停反馈（按压缩放、卡片轻抬、操作条滑入）；时长分级＝微交互 140ms / 常规 220ms / 面板与消息 320ms；统一指数减速缓动 `cubic-bezier(0.16,1,0.3,1)`（不用回弹/弹性曲线）；**只动 transform 与 opacity**；全量提供 `prefers-reduced-motion` 降级。标准取自 `frontend-design` 与 `impeccable` 技能手册；原型已加动效层（可运行对照）。
  - 点缀色：**浅蓝 `#63A6EC`**（深 `#3F83D6`、浅底 `#EAF3FC`）；原型中的调色板是试调工具，**不进入正式版**。
  - 结构：侧栏可折叠（折叠态点灵图标展开；展开态用品牌行右端小图标收起；状态记忆）；去掉顶栏面包屑与页脚；**「后台工作」并入「设置 → 备份与数据」——导航定为 5 项**（概览 / 对话 / 资料 / 浏览器 / 设置）。
  - 对话页：气泡（用户右浅蓝 / 灵左灰 + 头像）；「工作记录」可折叠卡（含「N 项同时」）；**消息悬浮操作条**（用户：复制/编辑/删除；灵：复制/重新生成/删除。编辑=行内编辑并明示「其后回复将重新生成」；删除=确认弹窗、删整轮）——参照 WorkBuddy 样式与业内做法（ChatGPT/Claude）；**多选（批量删除）入口在「⋯」菜单，操作条仅在进入多选后出现**；输入区＝环境标签 + 卡片式输入 + ＋附件 / 完全访问 / 模型与思考强度 / 发送；「⋯」菜单＝对话选项（批量删除 / 任务工作副本 / 模型设置）。
  - 新增界面：设置内补「MCP 工具连接」（服务器增删/启停）与「技能包（来源目录）」。
  - 明确不做（留作后续）：引用回复（无引用语义）；编辑后「版本切换」（后端已有分支能力，属增强项）。
  - 视觉基线：宿主机 `.workbuddy/design/ui-prototype-v1.html`（助手工作区，不进 Git；实现中以此对照）。
- 阶段2 机制结论（承接前版计划，已归档）：确认逻辑在 `BEFORE_TOOL` 钩子（策略件，机制与策略分离）；复用按对话独立表先例；事件只增字段（`access: "full"`）；**沙箱、审计、目录授权、浏览器点击审批全部不变**；**持久性＝按对话持久保存**（所有者定案）。
- 前端现状：`frontend/src/` 约 40 个组件文件（chat / settings / tasks / browser / content / overview / onboarding + shared）；本次为**整体重写**——保持 API 契约不变，换样式、重组结构与交互。

## 不改什么（边界）

- 后端 API 契约：除新增 access 两端点外，不增改既有端点；事件只新增 `access` 字段；
- 对话循环、模型接入、权限、沙箱、审计、任务副本、浏览器等**行为语义不变**——前端只换界面与结构，不换功能集合；
- 不碰 `models/`、`part2_retired/`；不做打包（保持源码迭代）；不改 `start.bat`（保持 GBK + CRLF）；
- 不动 `docs/愿景/`；不引入新的第三方前端依赖（实现中如确需，先呈报）；
- 不删除既有后端测试；前端测试按新组件结构重写，但覆盖面只增不降。
