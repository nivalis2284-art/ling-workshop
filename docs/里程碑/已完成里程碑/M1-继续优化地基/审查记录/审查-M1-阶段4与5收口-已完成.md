三个缺陷都用“先离线回放脱敏 trace 复现 → 补最小失败回归 → 再修”的方式处理，且**都没有放宽任何一致性、参数或终止校验**。

|---|---|---|---|---|
| 1 | `tools` 场景 `blocked` / `model_malformed_stream` / 3 步 / 189 秒 | 中转在工具调用**续传块**把 `function.name` 显式发成 `null`；`ChatParser.feed` 走 `string(None)` → `ProtocolError(malformed_stream)`，第一帧即掐断流 | 续传块遇 `name`/`arguments` 为 `null` 按“本块无新片段”跳过（与同函数 content 分支既有的 `if value is not None` 一致）；完成仍要求 id 非空、name 非空、arguments 合法 JSON | `2f4a078` |

- **符号链接路径在本机仍属未验证**：本机 `Path.symlink_to()` 既不抛异常也不创建链接，原 `except (OSError, NotImplementedError): pytest.skip(...)` 守卫因此失效、用例继续执行并**误报失败**。已改为“创建后再确认链接是否真的存在”，不存在则按环境不可用跳过。**硬链接拒绝路径由 `test_scan_refuses_links_and_hard_links` 实际通过验证；符号链接路径为跳过，不等于通过。**
