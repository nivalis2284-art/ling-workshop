# 文档地图

> 本仓库的文档都在 `docs/` 下。本文件说明：**每个文件夹是干嘛的、新文档放哪、有哪些规矩。**
> 给 Agent 的执行规则在根目录 [`AGENTS.md`](../AGENTS.md)：AGENTS 管"怎么干活"，本文件管"东西放哪"。

## 文件夹一览

| 文件夹 | 职责（一句话） | 什么时候写 |
|---|---|---|
| [`01-愿景/`](01-愿景/) | 最高层长期依据（01-概念与原则、02-抽象需求），只读 | 罕见 |
| [`02-架构/`](02-架构/) | "现在是什么"：业务与能力全景、技术基线、沙箱、限制溯源 | 现实变化时 |
| [`03-路线图/`](03-路线图/) | "要做什么"：总览看板 + 各里程碑文档 | 状态变化随时 |
| [`04-计划/`](04-计划/) | 各阶段的计划（**开工前必写、所有者确认后执行**） | 每个阶段开工前 |
| [`05-执行记录/`](05-执行记录/) | 每个阶段"改了什么、结果如何" | 做完立刻写 |
| [`06-审查记录/`](06-审查记录/) | 每个阶段"验收对照、结论" | 每个阶段收尾 |
| [`07-交接/`](07-交接/) | 上下文过长时给接手者的交接文档（按日期） | 需要交接时 |
| [`08-模板/`](08-模板/) | 里程碑 / 计划 / 执行记录 / 审查记录 空白模板；写法规范见 [`../92-文档写作规范/`](92-文档写作规范/) | 罕见 |

另有三份顶层特殊文档：`90-使用说明.md`（面向使用者的操作手册）、`91-讨论笔记.md`（唯一允许随手覆盖的草稿区）、`92-文档写作规范/`（约束文档写法与产出质量，写文档前先读）。

## 新文档放哪

- 讲"现在是什么" → `02-架构/`；讲"要做什么" → `03-路线图/`；讲"这一步怎么做" → `04-计划/`；"做完的结果" → `05-执行记录/`；"验收结论" → `06-审查记录/`。
- 拿不准 → 先问所有者；不要新建计划外的文件夹。

## 阅读优先级（防误读）

- **默认必读**：[`../AGENTS.md`](../AGENTS.md)（怎么干活）→ 本文件（东西放哪）→ [`03-路线图/00-README.md`](03-路线图/00-README.md)（现在跑到哪）；按任务类型加读 [`02-架构/`](02-架构/) 对应文档。
- **按需读**：[`92-文档写作规范/`](92-文档写作规范/)（写文档前）、[`08-模板/`](08-模板/)、[`90-使用说明.md`](90-使用说明.md)、[`01-愿景/`](01-愿景/)（需求源头与最高依据）。
- **仅溯源读**：[`04-计划/`](04-计划/)、[`05-执行记录/`](05-执行记录/)、[`06-审查记录/`](06-审查记录/)、[`07-交接/`](07-交接/)——历史完成件；其中的"禁令 / 必须 / 不能"多数是**当时的阶段约定**，不代表现行规则（现行规则只看 AGENTS.md 与 02 / 03 的当前口径）。

## 命名规则

- **文件夹**：`01-愿景` … `08-模板`（按阅读顺序编号；原 `09-归档/` 已于 2026-10-14 取消，完成即标注、不搬家）。
- **每个文件夹**：目录页固定 `00-README.md`（排最前）；内容文档按 `01-`、`02-`… 编号，序号即阅读顺序。
- **顶层特殊文档**：`90-使用说明.md`、`91-讨论笔记.md`。
- **里程碑**：`M1-短名`（如 `M1-加回第二部分`）；阶段：`阶段1-短名`。
- **交接与归档**：按日期（如 `2026-10-13-交接.md`），时间即顺序。
- 同一里程碑的所有文档共用同一编号，一眼对应。

## 五条贯穿规则

1. **单一真源**：同一个信息只有一个"家"；其他地方放链接，不复制。
2. **完成即标注**：里程碑 / 阶段完成后，文档头部状态行改「已完成」、文件名加 `-已完成` 后缀，留在原文件夹——文件夹按「类型」分，不按「完成度」分，不搬来搬去。
3. **实时维护**：代码与文档在同一次提交里一起改；不允许"以后再补"。
4. **路径一律相对**：文档与配置里的路径只用相对路径；禁止本机绝对路径（`H:/...`、`C:\...`、`file:///`）——仓库要能在任何机器（含虚拟机）上克隆即用。
5. **旁白视角**：规则 / 设计 / 记录类文档用第三人称叙述，不出现「你」「我」等人称代词（「自我」等术语除外）；面向使用者的手册（如 `90-使用说明.md`）可用第二人称。

## 谁写谁批

- 计划由 Agent 写、**所有者确认**后才执行；执行记录由执行者写；审查记录由独立审查者写；所有者是最终决策人。
