# 模板（写文档的骨架）

| 模板 | 用途 |
|---|---|
| [`01-里程碑模板.md`](01-里程碑模板.md) | 新里程碑开立时 |
| [`02-计划模板.md`](02-计划模板.md) | 阶段计划（开工前必写、所有者确认后执行） |
| [`03-执行记录模板.md`](03-执行记录模板.md) | 阶段完工立刻写 |
| [`04-审查记录模板.md`](04-审查记录模板.md) | 独立复核、阶段收尾 |

模板规定「骨架长什么样」；每类文档的合格标准、必填项理由与反模式，见 [`../92-文档写作规范/`](../92-文档写作规范/)——写之前先读对应分则。
