# 文档写作规范（Agent 工作产出标准）

> **定位声明**：本系列约束**文档的写法与质量**；唯一例外是第 6 份《[`06-AI工作习惯.md`](06-AI工作习惯.md)》——那一份管「怎么干活」的防坑习惯。
> 目的是防止后续开发把文档和结构搞得乱七八糟——每份文档有明确的合格标准，写完后能对着自查，而不是每次凭感觉。
>
> 与 AGENTS.md 的分工：AGENTS.md 管「怎么干活」（纪律、流程、Git），本系列管「产出物长什么样、怎么算合格」。
> 每条规则都带「为什么」——理解理由才能正确例外，死记条款只会僵化。
