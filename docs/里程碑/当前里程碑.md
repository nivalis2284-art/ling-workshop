## 目标与验收边界

同一灵在一条用户可感知的主干中持续交流，工作在独立上下文执行、压缩并回归；主干旧历史按确定性闸门及日历整理为多个有发生时间、来源和原文入口的事件。逐步发展可更正的记忆与有证据的召回，不让摘要改写原文、权限、原生协议或执行事实。

- [ ] 唯一产品主干与工作分支归属明确，旧会话/编辑树/用户资料可追溯保留。
- [ ] 工作分支可以在安全边界压缩进行中过程并继续执行，主干历史及压缩状态不受影响；不支持的协议能力明确安全停止。
- [ ] 工作结果按真实执行/交付状态归档并幂等追加主干，不覆盖主干后来的消息或解除 unknown。
- [ ] 主干定时反思可配置时间/时区/年龄/阈值/模型/预算，低于阈值零模型调用且不误标处理；满足条件后生成多个独立、可纠正事件。
- [ ] 原文、时间、来源和完整性可核验；跨主干/分支回忆受显式关系和当前权限控制，来源失效同步作用于摘要及派生内容。
- [ ] 进一步完成长期记忆提炼、关联召回和高级整理；各后续范围单独规划、授权与验收。
