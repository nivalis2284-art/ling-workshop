## 目标与验收边界

让灵的工作成为可以持续积累、可靠回查的经历：同一聊天中完成工作后，后续模型输入只保留准确的短概况；人和 Agent 需要细节时，能够沿来源逐段查看。再逐步建立进行中工作的连续性、跨会话事件、记忆提炼与关联召回、后台整理。

**必须达成**（各项仍待对应阶段实施和验收）：

- [ ] 明确结束的工作事件可逆折叠，后续实际模型请求排除其详细消息及原生工具回放；保留事件概况、真实状态与回查入口。
- [ ] 保存系统获准保留的原始经历及稳定来源；可分页回读，标明截断、缺失、脱敏和证据范围。摘要不覆盖原文，不冒充执行证据。
- [ ] 对话分支、编辑、重生成、删除、权限撤回、检查点恢复、unknown 副作用与备份恢复语义保持正确。
- [ ] 进行中工作具有独立、可验证的上下文连续性方案；超过窗口时不靠丢弃未完成工具交换继续执行。
- [ ] 经历逐步支持跨会话组织、可更正的记忆提炼及有来源的召回；能区分事实、偏好、解释和未验证推测。
- [ ] 整理与反思任务能持久调度、取消和重试，控制模型开销，并接受所有者查看、更正、关闭及迁移。

**可选，按证据决定**：向量扩展、图数据库、第三方记忆引擎、独立记忆模型、多子 Agent 整理。它们不是里程碑通过的先决技术选型。人格、主动活动及自我发展服务的整体恢复另行立项。

## 阶段与依赖

| 阶段 | 产品结果与主要验收 | 依赖 | 当前状态与证据 |
|---|---|---|---|
| **一：工作事件折叠与完整经历按需展开** | 原聊天内已明确结束的工作变成输入中的短概况；人可展开、Agent 可按目录分页回读；原文、分支与执行围栏不被改变。逐项条件见[正式计划](../计划/计划.md) | 现有第一部分；先补最小事件索引和可回读来源 | **研究与正式计划已交付**；本轮方案、离线基线与复核完成，功能未实施、未验收 |
| **二：进行中工作的上下文连续性** | 大工作在安全边界压缩已闭合的步骤、保留计划与待办，三协议续接和恢复可测；超过窗口的安全失败仍成立 | 阶段一的来源与投影；不能用摘要替代检查点 | 待后续研究、计划与授权 |
| **三：事件识别与跨会话组织** | 在人工标记基线之上减少边界管理；支持分组、拆合、更正与跨会话关联；越权及错误分支检索为零 | 阶段一稳定 ID/版本/可见性；阶段二与本阶段可按实际依赖调整顺序 | 待后续研究、计划与授权 |
| **四：长期记忆提炼与维护** | 从经历提炼有来源、时效与可信度的记忆；冲突、更正、失效、删除及旧资料选择性接纳可复验 | 事件与来源契约；先审计旧模块再决定复用 | 待后续研究、计划与授权 |
| **五：关联组织与混合召回** | 关键词、时间、语义及关系组合；相对简单基线证明收益，支持无据拒答、来源追溯及权限隔离 | 阶段三、四；图/向量均按实验决定 | 待后续研究、计划与授权 |
| **六：异步整理与反思** | 持久任务队列、去重、增量更新、取消重试、费用/模型配置；主对话不等待后台整理；反思保留推断标签 | 记忆与召回的可靠接口；阶段一只采用最小摘要作业 | 待后续研究、计划与授权 |

阶段一名称中的“完整经历”指**系统实际观察到且获准保留的记录**，不是已被工具截断的外部世界、未采集的日志或私有推理对象。必须呈现覆盖范围，不能补造缺失材料。

## 关键决策与理由

| 日期 | 性质 | 决策与理由 |
|---|---|---|
| 2026-10-17 | 所有者已确定 | 正式创建独立 M2，阶段一优先深入研究；本轮不实施产品功能、不迁移真实数据、不新增付费模型测试 |
| 2026-10-17 | 工程拆分 | 将进行中工作连续性单列阶段二。当前运行器会因完整工具交换超窗口安全终止；“结束后折叠”无法解决这一问题，不能承诺阶段一支持单次运行无限增长 |
| 2026-10-17 | 推荐方案，待后续实施评审 | 阶段一采用原始记录、事件索引、可重建输入投影分层；投影先于预算选择及原生回放，检查点与副作用证据独立保存 |
| 2026-10-17 | 推荐方案，待所有者确认体验 | 明确标记的聊天工作与明确关联的独立任务优先；自动折叠只发生在事件关闭且安全条件满足后。普通回合 completed 不等于工作完成；未标记历史可人工选段 |
| 2026-10-17 | 工程选型方向 | 阶段一优先沿用 SQLite 和现有 Harness，借鉴开源分层/外存思想；不直接引入整套记忆引擎。版本、许可及成本以[研究审查](../审查记录/审查.md)为依据 |
