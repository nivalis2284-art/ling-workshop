## 目标与验收边界

让灵的工作成为可以持续积累、可靠回查的经历：同一聊天中完成工作后，后续模型输入只保留准确的短概况；人和 Agent 需要细节时，能够沿来源逐段查看。再逐步建立进行中工作的连续性、跨会话事件、记忆提炼与关联召回、后台整理。

**必须达成**（阶段一有离线对应证据，但整个 M2 仍未验收；阶段二～六尚未实施）：

- [ ] 明确结束的工作事件可逆折叠，后续实际模型请求排除其详细消息及原生工具回放；保留事件概况、真实状态与回查入口。阶段一离线对应已通过；真实 provider 与所有者体验待验。
- [ ] 保存系统获准保留的原始经历及稳定来源；可分页回读，标明截断、缺失、脱敏和证据范围。摘要不覆盖原文，不冒充执行证据。阶段一 64 KiB 分块与 32 KiB/8 页读取上限的离线对应已通过。
- [ ] 对话分支、编辑、重生成、删除、权限撤回、检查点恢复、unknown 副作用与备份恢复语义保持正确。阶段一离线对应已通过；真实模型活动撤回未验。
- [ ] 进行中工作具有独立、可验证的上下文连续性方案；超过窗口时不靠丢弃未完成工具交换继续执行。M2 阶段二未实施。
- [ ] 经历逐步支持跨会话组织、可更正的记忆提炼及有来源的召回；能区分事实、偏好、解释和未验证推测。M2 阶段三～五未实施。
- [ ] 整理与反思任务能持久调度、取消和重试，控制模型开销，并接受所有者查看、更正、关闭及迁移。阶段一只验证了可选 summary runner 的离线契约；阶段六未实施。

**可选，按证据决定**：向量扩展、图数据库、第三方记忆引擎、独立记忆模型、多子 Agent 整理。它们不是里程碑通过的先决技术选型。人格、主动活动及自我发展服务的整体恢复另行立项。
