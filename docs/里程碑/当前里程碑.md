## 目标与验收边界

灵能在持续主干中处理日常交流，也能创建**具有持续身份**的子 Agent 独立完成复杂工作。子 Agent 可接受指导、暂停、休眠、在重启后合法恢复，并以同一身份开启后继阶段；完整过程保留，主干只收到真实结果、证据和回忆入口。四档操作与三档网络由服务端统一执行，任何实际启用的工具、任务、MCP、浏览器或命令通道都不能绕过。

- [ ] 子 Agent 的身份、工作阶段、单次运行和不可变归档分开；归档不等于身份销毁。
- [ ] 子 Agent 自主规划、调用获准工具并形成结果；主干可同时正常交流；简单任务不强制委托。
- [ ] 指导、暂停、普通回合结束、恢复、休眠、后继唤醒和 unknown 防护具有真实持久语义。
- [ ] 文件、命令、MCP、浏览器、任务、后台均走统一策略门；L1～L4 的行为可验证且旧权限不静默提权。
- [ ] N0/N1/N2 对 Agent 自主网络通道真实生效；不能可靠隔离的组合明确禁用，不以 UI 冒充。
- [ ] 子 Agent 权限不超过父级上限和执行环境能力；父级降权立即影响后续调用。
- [ ] 阶段结果按真实执行/交付状态归档、幂等回归，并能按身份与阶段追溯完整经历。
- [ ] 原文、来源、附件、私有 checkpoint、effect 与人工未知状态分别保护；迁移、备份与恢复可回退。
- [ ] 阶段二再深化长期压缩与休眠延续；阶段一不宣称无限上下文、完整意识连续性或未验证的语义质量。
