## 目标与验收边界

灵能在持续主干中处理日常交流，也能创建工作分支；工作分支就是承担该任务的子 Agent。它拥有独立工作上下文、目标、执行、指导、历史与状态，可安全休眠，并在需要时以同一 branch 身份恢复原任务理解、关键决策、进度、未完成项与已归档经历。主干只接收必要结果和回忆入口，并继续正常交流。

- [x] 工作 branch 的 ID 就是稳定子 Agent ID；不另建外层身份，也不以新 ID、历史引用或摘要冒充连续。三协议唤醒测试证明同 branch/同工作树延续。
- [x] 同 branch 的工作 conversation 作为历史树；任务状态修订保存目标/决策/进度/未完成/来源；episode 表示每次唤醒阶段，run 表示一次执行。迁移 037 与生命周期测试提供证据。
- [x] 创建、实际消费指导、普通回合结束、真实暂停、重启恢复、安全休眠和同 branch 后继 episode 具有不同持久语义。迁移 038、运行恢复与指导消费测试提供证据；真实 owner 体验仍未验收。
- [x] 旧 episode 与归档不可变；唤醒不重放完成 checkpoint/effect；凡是未知、待审或来源失效都阻断自动继续。自动化测试覆盖归档 hash、旧 effect/checkpoint 与 legacy 回填；完整未知交付故障矩阵仍未全部实测。
- [x] 完整任务经历可由 branch、episode、run、来源与回归追溯；UI 原文入口使用真实 `work-archive:<archive_id>` 经历标识。多归档 owner 体验仍待验收。
- [ ] 四档操作与三档网络是阶段一最终能力；服务端实际执行、主体不高于父级、旧 full 不静默提权，无法隔离的通道明确禁用。
- [ ] 阶段二再深化长期压缩、多次休眠的语义延续和事件组织；阶段一不宣称无限上下文、完整意识连续性或未验证的语义质量。
- [ ] 原文、来源、附件、私有 checkpoint、effect 与人工 unknown 分别保护；迁移、备份与恢复可回退。
