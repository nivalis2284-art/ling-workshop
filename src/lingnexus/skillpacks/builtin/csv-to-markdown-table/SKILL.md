# 把 CSV/TSV 转成 Markdown 表格

只用到读文件与写文件，不需要任何外部程序。

## 1. 先看清文件本身

- `read_file` 读前面一小段，确认：
  - 分隔符是逗号还是制表符（`.tsv` 一般是制表符）；
  - 第一行是表头还是数据；
  - 有没有引号包裹的字段（字段内部可能含分隔符）。
- 文件很大时，先只读开头，别一次全读进来。

## 2. 再决定表格长什么样

- 列太多时，**只保留需要的列**，而不是原样搬运。先问清楚要看哪些列。
- 表头为空或含义不明时，如实标注，不要自己编一个像模像样的列名。
- 数字列保持原样，不要擅自四舍五入或换算单位。

## 3. 写出 Markdown

- 结构：一行表头 + 一行分隔（`| --- |`）+ 数据行。
- 字段里的竖线 `|` 要转义成 `\|`，否则会把表格撑破。
- 用 `create_file` 写新文件；要覆盖已有文件用 `write_file`。

## 4. 复核

- 数一下写出的数据行数与源文件的数据行数是否一致（表头不算）。
- `read_file` 回看开头几行，确认表格渲染正确、列数一致。
- 行数对不上就说明解析错了（常见原因：字段内含分隔符或换行），回头重做第 1 步。

## 不要做

- 不要为了"好看"丢数据或改数值。
- 不要在没核对行数的情况下声称转换完成。
